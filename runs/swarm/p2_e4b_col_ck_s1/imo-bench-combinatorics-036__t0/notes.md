The minimum number of adjacent swaps required to transform any permutation to any other permutation of $N$ elements arranged linearly is equal to the maximum number of inversions possible, which occurs when transforming the identity permutation to the reverse permutation $(N, N-1, \ldots, 1)$.
The number of inversions is $\binom{N}{2}$.
Formula: $D_{line}(N) = \frac{N(N-1)}{2}$.

Formula: $D_{cycle}(N) = \lfloor N^2/4 \rfloor$.
