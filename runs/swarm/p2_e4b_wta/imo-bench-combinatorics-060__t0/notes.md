### [W4, round 1]
ANALYSIS OF SUMSET SIZE:
The problem asks to minimize the size of the sumset $S = \{ t_i+t_j \mid 0\le i \le j \le 86 \}$. Generally, to minimize the number of distinct sums, one must maximize the number of collisions ($t_i + t_j = t_k + t_l$). This occurs when the sequence $t_i$ is highly clustered or forms an arithmetic progression (AP). Sparse sequences tend to maximize the sumset size.

CONSTRUCTION OF OPTIMAL SEQUENCE:
We have $N=87$ points ($t_0$ to $t_{86}$) spanning a range $M=171$. We need to divide $M$ into $N-1=86$ steps. The average step size is $171/86 \approx 1.99$.
To make the sequence as AP-like as possible, we must use steps of size $\lfloor 171/86 \rfloor = 1$ and $\lceil 171/86 \rceil = 2$.
Let $k$ be the number of steps of size 2, and $86-k$ be the number of steps of size 1.
$2k + 1(86-k) = 171 \implies k + 86 = 171 \implies k = 85$.
We require 85 steps of size 2 and 1 step of size 1.

A concrete construction (placing the single step of size 1 at the beginning for simplicity) is:
t_0 = 0
t_1 = 1 (Step size 1)
t_2 = 3 (Step size 2)
t_3 = 5 (Step size 2)
...
t_86 = 1 + 2 * 85 = 171.

This sequence $t_i$ is the best candidate for minimizing the number of distinct sums.
