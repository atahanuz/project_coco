Example polynomial: $P(x) = x^2 + x$.
Verification: $P(k) = k(k+1)$, which is always even, so $P(k) \equiv 0 \pmod 2$.

**Case $n=3$:**
The minimum number of non-zero coefficients is 2.
Example polynomial: $P(x) = x^3 - x$.
Verification: $P(k) = k(k^2-1) = (k-1)k(k+1)$, which is a product of three consecutive integers and is always divisible by 3.

**Case $n=4$:**
The minimum number of non-zero coefficients is 2.
Example polynomial: $P(x) = x^4 - x^2$.
Verification: $P(k) = k^2(k^2-1)$. If $k$ is even, $k^2$ is divisible by 4. If $k$ is odd, $k^2 \equiv 1 \pmod 4$, so $k^2-1$ is divisible by 4. In both cases, $P(k) \equiv 0 \pmod 4$.

**Case $n=5$:**
The minimum number of non-zero coefficients is 2.
Example polynomial: $P(x) = x^5 - x$.
Verification: By Fermat's Little Theorem, for any integer $k$, $k^5 \equiv k \pmod 5$. Thus $P(k) = k^5 - k \equiv 0 \pmod 5$.
