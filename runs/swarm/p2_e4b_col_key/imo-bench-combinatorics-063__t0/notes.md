## Concrete Proof Attempt: Injectivity for n=5, k=2
**Claim to verify:** If $C(L_1) = C(L_2)$, then $L_1 = L_2$.

$C(L)$ is the set of all strings $S$ such that $d(L, S) = 2$. We assume $L_1 \neq L_2$ and investigate contradictions.

**Case 1: $d(L_1, L_2) = 1$.**
Let $L_1$ and $L_2$ differ only at position $i$. $L_2 = L_1 \oplus e_i$.
Consider a string $S \in C(L_1)$ formed by flipping bits at positions $j, k$ where $j, k \neq i$. (There are $\binom{4}{2}=6$ such strings).
$d(L_1, S) = 2$.
Now calculate $d(L_2, S)$. Since $L_2$ and $L_1$ agree everywhere except $i$, and $S$ was created by flips at $j, k$:
1. At position $i$: $L_2$ differs from $L_1$, but $S$ matches $L_1$ at $i$. Thus, $L_2$ differs from $S$ at $i$. (Distance contribution: 1)
2. At positions $j, k$: $L_1$ and $L_2$ agree. $S$ differs from $L_1$ (and $L_2$) at $j, k$. (Distance contribution: 2)
Total distance: $d(L_2, S) = 1 + 2 = 3$.
Since $C(L_2)$ only contains strings $S'$ such that $d(L_2, S')=2$, the string $S$ generated above cannot be in $C(L_2)$.
**Conclusion for d=1:** $C(L_1) \neq C(L_2)$.

**Case 2: $d(L_1, L_2) = 2$.**
Let $L_1$ and $L_2$ differ only at positions $i$ and $j$. $L_2 = L_1 \oplus e_i \oplus e_j$.
Consider the string $S$ formed by flipping bits at positions $i$ and $j$ in $L_1$.
$S = L_1 \oplus e_i \oplus e_j = L_2$.
$d(L_1, S) = 2$, so $S \in C(L_1)$.
However, $d(L_2, S) = d(L_2, L_2) = 0$.
Since $C(L_2)$ only contains strings $S'$ such that $d(L_2, S')=2$, $S$ cannot be in $C(L_2)$.
**Conclusion for d=2:** $C(L_1) \neq C(L_2)$.

**Necessary Condition Summary:**
For $n=5, k=2$, if $C(L_1) = C(L_2)$, then $L_1$ and $L_2$ must satisfy $d(L_1, L_2) \notin \{1, 2\}$. Given the constraints imposed by the triangle inequality, it is highly likely that no solution exists for $d \ge 3$ either. The necessary condition for $C(L_1) = C(L_2)$ is $L_1 = L_2$.

### [W1, round 2] Formal Proof of Injectivity for n > 2k
**Goal:** To prove that if $n > 2k$, the mapping $L \mapsto C(L)$ is injective, i.e., $C(L_1) = C(L_2) \implies L_1 = L_2$.

**Setup:**
Assume for contradiction that $C(L_1) = C(L_2)$ while $L_1 \neq L_2$. Let $d = d(L_1, L_2) \ge 1$.
Let $I$ be the set of $d$ positions where $L_1$ and $L_2$ differ ($|I|=d$). Let $\bar{I}$ be the remaining $n-d$ positions.
Let $S$ be any string such that $d(L_1, S) = k$. By assumption $C(L_1) = C(L_2)$, we must have $d(L_2, S) = k$.

**Analysis of Distances:**
We analyze the contribution of positions in $I$ and $\bar{I}$ to the distances.
1. For $j \in \bar{I}$: $L_1(j) = L_2(j)$. The contribution to $d(L_1, S)$ and $d(L_2, S)$ is the same. Let $k_{\bar{I}}$ be the number of differences here.
2. For $j \in I$: $L_1(j) \neq L_2(j)$.
   Let $k_{I, 1}$ be the number of positions in $I$ where $S$ differs from $L_1$. (This contributes $k_{I, 1}$ to $d(L_1, S)$).
   Let $k_{I, 0}$ be the number of positions in $I$ where $S$ matches $L_1$. ($k_{I, 0} = d - k_{I, 1}$).

The total distance $d(L_1, S) = k_{I, 1} + k_{\bar{I}} = k$. Thus, $k_{\bar{I}} = k - k_{I, 1}$.

Now we calculate $d(L_2, S)$:
*   In $\bar{I}$, the distance contribution is $k_{\bar{I}}$.
*   In $I$:
    *   If $S$ matches $L_1$ ($k_{I, 0}$ positions), then $S$ differs from $L_2$ because $L_1$ and $L_2$ differ. Contribution: $k_{I, 0}$.
    *   If $S$ differs from $L_1$ ($k_{I, 1}$ positions), then $S$ must match $L_2$ (since $L_1$ and $L_2$ are complements at these positions). Contribution: 0.

Total distance $d(L_2, S) = k_{\bar{I}} + k_{I, 0} = (k - k_{I, 1}) + (d - k_{I, 1}) = k + d - 2k_{I, 1}$.

**Contradiction:**
If $C(L_1) = C(L_2)$, we require $d(L_2, S) = k$.
$k = k + d - 2k_{I, 1} \implies 2k_{I, 1} = d$.
This must hold for *every* $S$ such that $d(L_1, S)=k$.

If $d>0$, we show we can always construct an $S$ that violates this condition, contradicting the assumption $C(L_1) = C(L_2)$.
1. **Case $d \le k$:** Choose $k_{I, 1} = d$. This means $S$ flips $L_1$ at all $d$ positions in $I$. We need $k_{\bar{I}} = k-d$. Since $n>2k \ge 2d$, $n-d \ge k-d \ge 0$, so such an $S$ exists. For this $S$, $d(L_2, S) = k + d - 2d = k - d < k$. Thus $S \notin C(L_2)$, so $C(L_1) \neq C(L_2)$.
2. **Case $k < d \le 2k$:** Choose $k_{I, 1} = k-1$. This means $S$ flips $L_1$ in $k-1$ positions within $I$. We need $k_{\bar{I}} = 1$. Since $n > 2k$, we have $n-d \ge n-2k \ge 1$, so we can always find a position in $\bar{I}$ to flip. For this $S$, $d(L_2, S) = k + d - 2(k-1) = d - k + 2$. Since $d>k$, $d-k \ge 1$, so $d-k+2 \ge 3$. If $d=2k$, $d-k+2 = k+2 \neq k$. If $k < d < 2k$, then $d-k+2 > k$. In all subcases, $d(L_2, S) \neq k$. Thus $S \notin C(L_2)$, so $C(L_1) \neq C(L_2)$.

**Conclusion:** Since for any $d>0$ we can construct an $S$ proving $C(L_1) \neq C(L_2)$, we must have $d=0$, implying $L_1 = L_2$. The mapping is injective.
***
This formal proof confirms that the set $C$ uniquely identifies $L$ when $n>2k$. Therefore, only 1 guess is required to guarantee a correct answer.
