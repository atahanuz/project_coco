$$f(T_1)f(T_2) = 2^{|T_1 \cap A|} \cdot 2^{|T_2 \cap A|} = 2^{|T_1 \cap A| + |T_2 \cap A|}$$

$$f(T_1 \cup T_2)f(T_1 \cap T_2) = 2^{|(T_1 \cup T_2) \cap A|} \cdot 2^{|(T_1 \cap T_2) \cap A|}$$

$$(T_1 \cup T_2) \cap A = (T_1 \cap A) \cup (T_2 \cap A)$$
$$(T_1 \cap T_2) \cap A = (T_1 \cap A) \cap (T_2 \cap A)$$

$$|X_1| + |X_2| = |X_1 \cup X_2| + |X_1 \cap X_2|$$

$$|X_1 \cup X_2| = |X_1| + |X_2| - |X_1 \cap X_2|$$

$$|X_1| + |X_2| = |X_1 \cup X_2| + |X_1 \cap X_2|$$
