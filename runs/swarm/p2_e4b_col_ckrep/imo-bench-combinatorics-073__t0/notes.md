### Focused Investigation on $r_a=r_b=m$ (Constraint 2)

**Goal:** Bound the relationship between $m$ and the number of distinct column sums ($|D_m|$) arising from rows $R_m$ (rows having $m$ reserved seats).

**1. Intersection Constraint ($J_a \cap J_b = \emptyset$):**
Let rows $a$ and $b$ have $r_a = r_b = m$. If there were a column $j$ such that $A_{a, j} = 1$ and $A_{b, j} = 1$, then the two reserved seats $S_1=(a, j)$ and $S_2=(b, j)$ would have the same row sums ($r_a = r_b = m$) and the same column sum ($c_j = c_j$). Since $a \neq b$, $S_1 \neq S_2$, which violates Constraint 1. Therefore, the sets of columns used by row $a$ ($J_a$) and row $b$ ($J_b$) must be completely disjoint. This means the $2m$ reserved seats occupy $2m$ distinct columns.

**2. Column Sum Uniqueness within a Row ($m_i=m$):**
Consider a single row $i$ where $r_i=m$. Let $S_1=(i, j_1)$ and $S_2=(i, j_2)$ be two reserved seats in this row ($j_1 \neq j_2$). If $c_{j_1} = c_{j_2}$, then $S_1$ and $S_2$ would share the same row sum ($r_i=m$) and the same column sum ($c_{j_1}=c_{j_2}$). Since $j_1 \neq j_2$, $S_1 \neq S_2$, which violates Constraint 1. Therefore, every reserved seat in row $i$ must contribute to a unique column sum. For $r_a=m$ and $r_b=m$, this implies $m_a = m$ and $m_b = m$.

**3. Disjointness of Column Sum Sets:**
Let $D_m$ be the set of all distinct column sums generated by reserved seats in $R_m$. If $c^*$ was generated by both row $a$ and row $b$, let $(a, j)$ be the seat in row $a$ contributing to $c^*$, and $(b, j')$ be the seat in row $b$ contributing to $c^*$. Then $(a, j)$ and $(b, j')$ share row sum $m$ and column sum $c^*$. Since $a \neq b$, Constraint 1 is violated. Thus, the sets of column sums generated by different rows in $R_m$ must be disjoint.

**4. Bounding m:**
If we assume $R_m$ contains at least two rows ($|R_m| \ge 2$), then the total number of distinct column sums $|D_m|$ is at least $m_a + m_b + \dots$.
For the minimal case ($|R_m| = 2$, rows $a$ and $b$):
$|D_m| = m_a + m_b = m + m = 2m$.
Since the total number of columns is 200, the number of distinct column sums $|D_m|$ cannot exceed 200.
Therefore, $2m \le 200$, leading to the bound $m \le 100$.
