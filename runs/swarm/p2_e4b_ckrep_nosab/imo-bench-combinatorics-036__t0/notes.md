### Analysis of State Space and Distance (Task Part 1)

Let $N=199$. The set of assignments is $S_N$. The action of rotation $C_N$ on $S_N$ is defined by $R_k(\sigma) = \sigma \circ C_k$, where $C_k$ is the cyclic permutation $(0 \to k, 1 \to k+1, \ldots)$. The state space is the quotient space $X = S_N / C_N$.

The generating set is $G = \{t_0, t_1, \ldots, t_{N-1}\}$, where $t_i$ is the adjacent transposition swapping elements at vertices $V_i$ and $V_{i+1 \pmod N}$.

The distance $d(\sigma_A, \sigma_B)$ in the full space $S_N$ is the minimum number of adjacent swaps required, which is known to be the number of inversions in $\sigma_B \sigma_A^{-1}$.

The distance in the rotational quotient space $d_X([\sigma_A], [\sigma_B])$ is defined as:
$$d_X([\sigma_A], [\sigma_B]) = \min_{\sigma_B' \in [\sigma_B]} d(\sigma_A, \sigma_B')$$
where $[\sigma_B] = \{R_k(\sigma_B) : k \in \{0, \ldots, N-1\}\}$.

The task requires finding the diameter $n = \max_{[\sigma_A], [\sigma_B] \in X} d_X([\sigma_A], [\sigma_B])$.

The constraint modifies the distance because we are allowed to choose the most convenient rotation of the target configuration $\sigma_B$ to minimize the required swaps from the starting configuration $\sigma_A$. This allows us to "align" the start and end states optimally relative to the rotational structure.

If $d(\sigma_A, \sigma_B)$ is the distance without symmetry, the rotational distance $d_X$ is always less than or equal to $d(\sigma_A, \sigma_B)$.
$$d_X([\sigma_A], [\sigma_B]) \le d(\sigma_A, \sigma_B)$$
The difference $d(\sigma_A, \sigma_B) - d_X([\sigma_A], [\sigma_B])$ measures the maximum reduction in distance achieved by exploiting rotational symmetry.
