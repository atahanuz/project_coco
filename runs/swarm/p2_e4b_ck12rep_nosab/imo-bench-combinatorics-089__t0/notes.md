Analysis of the constraint $A_{i, j} = ai + bj$ for a $2 \times 2$ block.
Let the colors in a $2 \times 2$ block starting at $(i, j)$ be:
$C_{i, j} = ai + bj$
$C_{i+1, j} = ai + bj + a$
$C_{i, j+1} = ai + bj + b$
$C_{i+1, j+1} = ai + bj + a + b$

For these four colors to use at most 3 distinct colors, at least two of these values must be equal. We assume $a, b > 0$ (monotonic, non-constant increments).

If $a \neq b$:
The four values are $C_0, C_0+a, C_0+b, C_0+a+b$.
Since $a>0$ and $b>0$, none of the values are equal to $C_0$ or $C_0+a+b$ (unless $a=0$ or $b=0$, which violates the "non-constant increments" assumption).
If $a \neq b$, then $C_0+a \neq C_0+b$.
Furthermore, $C_0+a < C_0+a+b$ and $C_0+b < C_0+a+b$.
Since $a, b > 0$, all four values are strictly distinct. This configuration yields 4 distinct colors, violating the constraint (which requires $\le 3$ distinct colors).

If $a = b$:
The four values become $C_0, C_0+a, C_0+a, C_0+2a$.
The set of distinct colors is $\{C_0, C_0+a, C_0+2a\}$, which has exactly 3 distinct colors (assuming $a>0$). This satisfies the constraint.

Conclusion: Monotonic solutions of the form $A_{i, j} = ai + bj$ only satisfy the constraint if $a=b$.
