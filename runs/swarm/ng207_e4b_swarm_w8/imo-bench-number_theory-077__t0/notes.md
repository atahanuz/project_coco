Analysis of the operation $n \to n' = k + 3d$, where $n = 10k + d$.

**Modular Arithmetic Properties:**

1.  **Modulo 3:**
    We found that $n' \equiv n - d \pmod 3$.
    (Since $n \equiv k+d \pmod 3$ and $n' \equiv k \pmod 3$, substituting $k \equiv n-d$ gives $n' \equiv n-d$).
    A simple invariant $n' \equiv n \pmod 3$ only holds if $d \equiv 0 \pmod 3$.

2.  **Modulo 9:**
    We found that $n' \equiv n + 2d \pmod 9$.
    (Since $n \equiv k+d \pmod 9$ and $n' \equiv k+3d \pmod 9$, substituting $k \equiv n-d$ gives $n' \equiv (n-d) + 3d \equiv n+2d$).
    A simple invariant $n' \equiv n \pmod 9$ only holds if $2d \equiv 0 \pmod 9$, which implies $d \equiv 0 \pmod 9$.

**Conclusion:**
There is no universal invariant of the form $n' \equiv n \pmod m$ for general $n$. The change in the remainder depends entirely on the last digit $d$ of $n$.
