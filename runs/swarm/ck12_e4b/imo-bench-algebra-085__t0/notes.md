I tested $n=1001$ using the index choices where all pairs are $(t_i, s_i) = (1, 1)$ for $i=1, \ldots, 1001$.
I tested the configuration $x_1 = 2014$ and $x_i = 0$ for $i=2, \ldots, 1000$.
In this case, the Left Hand Side (LHS) is $1001 \cdot x_1^2 = 1001 \cdot 2014^2 \approx 4.06 \times 10^9$.
The required Right Hand Side (RHS) is $2014 \cdot 1000 = 2,014,000 \approx 2.01 \times 10^6$.
Since LHS > RHS, this specific set of pairs for $n=1001$ violates the condition.

More generally, since $n=1001 > 1000$, by the Pigeonhole Principle, some index must be reused significantly, leading to a quadratic term in the sum $\sum x_{t_i}x_{s_i}$. This allows us to select a distribution $x_i$ that concentrates mass on a few indices, making the sum scale roughly as $n \cdot (\sum x_i)^2 / 1000^2$ times $1000$, resulting in a violation for large $n$.

This confirms that $n > 1000$ forces the existence of choices that violate the inequality, meaning the maximum $n$ must be $\le 1000$.

**Construction:** We choose $n=1000$ pairs following a cyclic structure: $(t_i, s_i) = (i, i \pmod{N} + 1)$ for $i=1, \ldots, N$.
The sum to bound is $Q = \sum_{i=1}^{N-1} x_i x_{i+1} + x_N x_1$.

**Proof:** The maximum value of $Q$ subject to $\sum x_i = S$ and $x_i \ge 0$ is achieved when $x_i = S/N$ for all $i$.
$Q_{\max} = N \cdot (S/N)^2 = S^2/N$.

We need to verify if $S^2/N \le S \cdot N$. This is equivalent to checking $S \le N^2$.
Substituting values: $2014 \le 1000^2 = 1,000,000$. This is true.

The maximum possible value of the sum is $Q_{\max} = 2014^2 / 1000 \approx 4056.2$.
The required upper bound is $S \cdot N = 2,014,000$.
Since $4056.2 \le 2,014,000$, the construction guarantees the inequality holds for all valid $x_i$. This proves $n \ge 1000$.
