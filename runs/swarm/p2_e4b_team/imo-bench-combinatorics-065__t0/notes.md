**Row Balance:**

The input argument to $h$ is $k_j = (i_0 + j) \pmod n$.
As $j$ ranges over $\{1, 2, \dots, n\}$, the values $k_j$ cover the entire set $\mathbb{Z}_n$ exactly once.
Since $h$ is balanced over $\mathbb{Z}_n$, the count of entries in Row $i_0$ corresponding to $I, M, O$ must each be $n/3$. Thus, rows are balanced.

**Column Balance:**

The input argument to $h$ is $k_i = (i + j_0) \pmod n$.
As $i$ ranges over $\{1, 2, \dots, n\}$, the values $k_i$ cover the entire set $\mathbb{Z}_n$ exactly once.
Since $h$ is balanced over $\mathbb{Z}_n$, the count of entries in Column $j_0$ corresponding to $I, M, O$ must each be $n/3$. Thus, columns are balanced.

### 2. Verification of Diagonal Balance (Constraint 3)

We consider two types of diagonals: anti-diagonals (constant $i+j$) and main-parallel diagonals (constant $j-i$). Since $n=1989$ is a multiple of 3, the main diagonals (of length $n$) must be balanced.

**Main-Parallel Diagonals ($j-i = K$):**
Consider a diagonal $D_K$ defined by $j = i+K$ (using modular arithmetic for indices, $1 \le i, j \le n$).
The input argument to $h$ is $k_i = (i + j) \pmod n = (i + (i+K)) \pmod n = (2i + K) \pmod n$.
For $D_K$ to be balanced, the sequence of values $k_i$ must cover $\mathbb{Z}_n$ exactly once (or multiple times, such that $h$ distributes equally). This happens if and only if the mapping $i \mapsto 2i + K \pmod n$ is a permutation of $\mathbb{Z}_n$.
This permutation holds if and only if $\gcd(2, n) = 1$.
Since $n=1989$ is odd, $\gcd(2, 1989) = 1$. Therefore, as $i$ runs from $1$ to $n$, the values $k_i$ cover all residues of $\mathbb{Z}_n$ exactly once.
Since $h$ is balanced, $D_K$ contains exactly $n/3$ entries mapped to $I, M,$ and $O$. Thus, main-parallel diagonals are balanced.

**Anti-Diagonals ($i+j = K$):**
In the toroidal sense (where the construction $A_{i,j} = h((i+j) \pmod n)$ is naturally defined), any anti-diagonal $D_K$ corresponds to all pairs $(i, j)$ such that $i+j \equiv K \pmod n$.
For a fixed $K$, every entry $A_{i,j}$ on $D_K$ is calculated using the same index input: $k = K \pmod n$.
Therefore, $A_{i,j} = h(K)$ for all entries on $D_K$. This means the diagonal $D_K$ is monochromatic.
