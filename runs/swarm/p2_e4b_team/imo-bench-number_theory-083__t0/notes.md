Analysis of the condition:
The given condition is that for any $p, q \in K$, there exists $r \in K$ such that $p+q \equiv 2r \pmod{2021}$.
Let $D = \{p-q \pmod{2021} : p, q \in K\}$ be the set of differences.
If we set $d = p-q$, then $p = q+d$. Substituting this into the condition:
$(q+d) + q \equiv 2r \pmod{2021}$
$2q + d \equiv 2r \pmod{2021}$
$d \equiv 2r - 2q \pmod{2021}$
$d \equiv 2(r-q) \pmod{2021}$.

Since $q, r \in K$, the difference $r-q$ is an element of $D$.
Thus, the set of differences $D$ must satisfy the constraint that every element $d \in D$ must be twice some element $d' \in D$ (i.e., $D \subseteq 2D$ in the ring $\mathbb{Z}_{2021}$). This relates $D$ to the subgroup generated by 2, as all such elements $2d'$ are multiples of 2.

**Goal:** Prove that any subgroup $K$ of $\mathbb{Z}_{2021}$ satisfies $K+K \subseteq 2K \pmod{2021}$ and find the possible cardinalities given $|K| \ge 3$.

$N = 2021$. We find the prime factorization: $2021 = 43 \times 47$. Since $N$ is odd, $\gcd(2, N) = 1$, which implies that 2 is invertible in $\mathbb{Z}_{2021}$. The inverse is $2^{-1} \equiv 1011 \pmod{2021}$.

**2. Condition for Subgroups:**
If $K$ is a subgroup of $(\mathbb{Z}_{2021}, +)$, then by definition of a subgroup:
a) $K+K \subseteq K$. In fact, $K+K = K$ (closure property).
b) $0 \in K$.

The condition $K+K \subseteq 2K$ simplifies to $K \subseteq 2K$.

**3. Proving $K \subseteq 2K$:**
Let $k \in K$. We must show there exists $r \in K$ such that $k \equiv 2r \pmod{2021}$.
Since 2 is invertible, we can solve for $r$:
$r \equiv 2^{-1}k \pmod{2021}$
Since $K$ is a subgroup, it is closed under multiplication by any element of $\mathbb{Z}_{2021}$ if we consider the structure relative to the generator, but more simply, since $K$ is a cyclic subgroup (being a subgroup of $\mathbb{Z}_N$), multiplication by a fixed element $a=1011$ maps $K$ onto itself. Thus, $r = 1011k \in K$.
Therefore, $K \subseteq 2K$, and consequently $K+K \subseteq 2K$ is rigorously proven for any subgroup $K$.

**4. Determining Cardinalities:**
The possible sizes of subgroups of $\mathbb{Z}_{2021}$ must be divisors of $N=2021$.
The divisors of $2021 = 43 \times 47$ are: $1, 43, 47, 2021$.
