### [W3, round 1]
**Verification of G for Bachata Subsets:**
The task was to confirm that any Bachata subset $S$ must contain the set $G$, specifically checking the necessity condition for the first 5 elements: $G_5 = \{0, 11, 20, 22, 31\}$.

A subset $S$ is Bachata if $0 \in S$, and for $n \in S$, $n+11 \in S$ and $n+20 \in S$.

1. $0 \in S$ (Required by definition).
2. Since $0 \in S$, then $0+11 = 11 \in S$ and $0+20 = 20 \in S$.
3. Since $11 \in S$, then $11+11 = 22 \in S$ and $11+20 = 31 \in S$.
4. Since $20 \in S$, then $20+11 = 31 \in S$ and $20+20 = 40 \in S$.

Since $0, 11, 20, 22, 31$ are all necessarily generated by applying the Bachata rules starting from 0, the necessity condition is confirmed for these five elements. Any Bachata subset $S$ must contain $G_5$.

### [W2, round 1]
Task: Prove that if $S$ is a Bachata subset, every $n \in S$ is of the form $11a + 20b$ where $a, b \ge 0$.

A set $S$ is Bachata if:
1. $0 \in S$.
2. If $n \in S$, then $n+11 \in S$ and $n+20 \in S$.

Proof strategy: Show that $S$ must be exactly the set of all non-negative linear combinations of 11 and 20, denoted $G = \{11a + 20b : a, b \ge 0\}$.

Step 1: Show $G \subseteq S$.
Since $0 = 11(0) + 20(0)$, $0 \in G$.
$G$ is closed under addition of 11: If $n = 11a + 20b \in G$, then $n+11 = 11(a+1) + 20b \in G$.
$G$ is closed under addition of 20: If $n = 11a + 20b \in G$, then $n+20 = 11a + 20(b+1) \in G$.
Since $S$ is the smallest set containing 0 and closed under addition of 11 and 20, it must contain all elements generated by these rules. Therefore, $G \subseteq S$.

Step 2: Show $S \subseteq G$.
We use structural induction/generation.
Base Case: $0 \in S$. $0 = 11(0) + 20(0)$, so $0 \in G$. The base case holds.
Inductive Step: Assume that every element $k \in S$ such that $k < n$ is of the form $11a + 20b$ with $a, b \ge 0$.
Consider $n \in S$. Since $n$ is a positive integer (if $n=0$, it's covered), $n$ must have been generated from 0 by a sequence of additions of 11 or 20.
If $n$ was generated in one step from some $m \in S$:
Case 1: $n = m + 11$. Since $n > 0$, $m = n-11$. If $n-11 \ge 0$, then $m < n$, so $m \in G$ by the inductive hypothesis. Thus $n = m + 11 \in G$.
Case 2: $n = m + 20$. Since $n > 0$, $m = n-20$. If $n-20 \ge 0$, then $m < n$, so $m \in G$ by the inductive hypothesis. Thus $n = m + 20 \in G$.
If $n$ is not directly generated by one step from $m < n$, then $n$ is generated by a sequence of steps. By the definition of the set $S$ (as the closure of $\{0\}$ under $+11$ and $+20$), any element $n \in S$ is the result of applying a sequence of operations $\{+11, +20\}$ to 0. If the sequence involves $k$ additions of 11 and $l$ additions of 20, then $n = 11k + 20l$. Since $k$ and $l$ are counts, $k \ge 0$ and $l \ge 0$. Thus $n \in G$.

Conclusion: Since $S \subseteq G$ and $G \subseteq S$, we have $S = G$. Therefore, any element $n$ in a Bachata subset $S$ must be of the form $11a + 20b$ where $a, b \ge 0$.

### [W1, round 1]
Task: Prove that any Bachata subset S must contain all elements of the form 11a + 20b where a, b >= 0.

Proof Outline:
Let T be the set of elements of the form 11a + 20b where a, b >= 0. We must show T is a subset of S for any Bachata set S.

1. Base Case: The element 0 is in T (when a=0, b=0). Since S is Bachata, 0 must be in S.
2. Inductive Step/Constructive Argument: Assume that an element n = 11a + 20b is in T. We want to show that if n is in S, then all elements generated from it by repeatedly adding 11 or 20 are also in S (which confirms they are in T and S).
    - If n is in S, by definition of a Bachata set, n + 11 must be in S.
      n + 11 = (11a + 20b) + 11 = 11(a+1) + 20b. This is an element of T (since a+1 >= 0, b >= 0).
    - If n is in S, by definition of a Bachata set, n + 20 must be in S.
      n + 20 = (11a + 20b) + 20 = 11a + 20(b+1). This is an element of T (since a >= 0, b+1 >= 0).

Since every element in T can be reached from 0 by a sequence of additions of 11 or 20, and since S is closed under these additions starting from 0, every element of T must belong to S.
The proof is complete.

### [W4, round 1]
A Bachata subset S must satisfy two conditions: 1) 0 is in S, and 2) S is closed under adding 11 and 20. Since the starting point is 0, any element n in S must be reachable by repeatedly adding 11 or 20 to 0. Therefore, any element n must be expressible in the form n = 11a + 20b, where a and b are non-negative integers. The set defined by these constraints is the smallest such set (the closure of {0} under {+11, +20}), and because any set satisfying the conditions must contain this minimal set, the conditions uniquely define this set. This set is the set of non-negative integer linear combinations of 11 and 20.
