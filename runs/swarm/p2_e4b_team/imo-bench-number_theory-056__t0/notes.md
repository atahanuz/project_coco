The difference is:
$P(k+1) - P(k) = \sum_{i=0}^n a_i [(k+1)^i - k^i]$.
Since $(k+1)^i - k^i = \sum_{j=0}^{i-1} \binom{i}{j} k^j$ for $i \ge 1$ (and 0 for $i=0$), we have:
$P(k+1) - P(k) = \sum_{i=1}^n a_i \left( \sum_{j=0}^{i-1} \binom{i}{j} k^j \right)$.

We can swap the order of summation to group coefficients of $k^j$:
$P(k+1) - P(k) = \sum_{j=0}^{n-1} k^j \left( \sum_{i=j+1}^n a_i \binom{i}{j} \right)$.
