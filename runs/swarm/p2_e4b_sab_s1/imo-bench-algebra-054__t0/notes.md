Equating the elements of the blocks, we have:
$$a_{n+d+k} = a_{n+k} \quad \text{for all } n \ge N \text{ and } k = 1, 2, \ldots, L.$$

We must show $a_{m+d} = a_m$ for all $m \ge N'$ for some starting index $N'$.

1.  **Case 1: $N+1 \le m \le N+L$**
    If we set $n=N$, the condition applies for $k = m-N$. Since $N+1 \le m \le N+L$, we have $1 \le m-N \le L$.
    Substituting $n=N$ and $k=m-N$ into the block periodicity condition:
    $$a_{N+d+(m-N)} = a_{N+(m-N)} \implies a_{m+d} = a_m.$$
    This establishes periodicity for $m$ in the range $[N+1, N+L]$.

2.  **Case 2: $m > N+L$**
    We need to show $a_{m+d} = a_m$. We construct appropriate values for $n$ and $k$.
    Choose $k = (m-1) \pmod{L} + 1$. This ensures $1 \le k \le L$.
    Let $n = m-k$. Since $m > N+L$ and $k \le L$, we have $n = m-k > N+L - L = N$. Thus, $n \ge N$.
    Now we apply the block periodicity condition using this $n$ and $k$. Since $n \ge N$ and $1 \le k \le L$:
    $$a_{n+d+k} = a_{n+k}$$
    Substituting $n+k = m$:
    $$a_{m+d} = a_m.$$
    This establishes periodicity for all $m > N+L$.

**Conclusion:** Combining Case 1 and Case 2, we have proven that $a_{m+d} = a_m$ for all $m \ge N+1$. Therefore, the sequence $a_n$ is eventually periodic with period $d$ starting at $N' = N+1$.
