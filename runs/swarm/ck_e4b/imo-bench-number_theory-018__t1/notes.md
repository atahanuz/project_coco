Part 1: Analysis of $X = k\mathbb{Z}$ being a good set.
Let $X = k\mathbb{Z}$ for $k \ge 1$.
If $a, b \in X$, then $a = k a'$ and $b = k b'$ for some integers $a', b'$.
We must check if $E = a^2 + i \cdot a \cdot b + b^2 \in X$ for any $i \in \mathbb{Z}$.
$E = (k a')^2 + i (k a') (k b') + (k b')^2$
$E = k^2 a'^2 + i k^2 a' b' + k^2 b'^2$
$E = k^2 (a'^2 + i a' b' + b'^2)$
Since $a', b', i$ are integers, $a'^2 + i a' b' + b'^2$ is an integer.
Thus, $E = k \cdot [k (a'^2 + i a' b' + b'^2)]$.
Since $k (a'^2 + i a' b' + b'^2)$ is an integer, $E$ is a multiple of $k$, meaning $E \in k\mathbb{Z} = X$.
Conclusion: $X = k\mathbb{Z}$ is always a good set for $k \ge 1$.
