## Task Analysis: Constraints on N (Condition (i) & (iii))

**Fundamental Constraint:**
Condition (i) states that every pair of the $N$ students belongs to exactly one study group. If the group sizes are $n_1, n_2, \dots, n_r$, this implies the sum of pairs generated by each group must equal the total number of pairs:
$$\sum_{i=1}^{r} \binom{n_i}{2} = \binom{N}{2}$$
Condition (iii) requires all $n_i$ to be odd.

**Parity Constraint on N:**
Analyzing the parity of $\binom{n_i}{2}$ based on $n_i \pmod 4$:
1. If $n_i \equiv 1 \pmod 4$, then $\binom{n_i}{2}$ is Even.
2. If $n_i \equiv 3 \pmod 4$, then $\binom{n_i}{2}$ is Odd.

Let $r_{odd}$ be the number of study groups whose size $n_i$ satisfies $n_i \equiv 3 \pmod 4$. The parity of the total number of pairs, $\binom{N}{2}$, must equal the parity of $r_{odd}$.

*   If $N \equiv 0 \text{ or } 1 \pmod 4$, $\binom{N}{2}$ is Even, so $r_{odd}$ must be **even**.
*   If $N \equiv 2 \text{ or } 3 \pmod 4$, $\binom{N}{2}$ is Odd, so $r_{odd}$ must be **odd**.

This provides necessary arithmetic constraints on $N$ based on the distribution of group sizes. For the specific case $N=579$, since $579 \equiv 3 \pmod 4$, the number of groups of size $3 \pmod 4$ must be odd.
