    $$T_{k+d} = (a_{(k+d)+1}, a_{(k+d)+2}, \ldots, a_{(k+d)+2025})$$

    $$a_{(k+d)+j} = a_{(k+j)+d} = a_{k+j}$$
    This holds for all $j=1, \ldots, 2025$. Therefore, $T_{k+d} = T_k$ for all $k \ge N$.
