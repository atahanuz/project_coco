Step 3: Establishing Periodicity.

(a_{m+1}, ..., a_{m+k}) = (a_{l+1}, ..., a_{l+k}).
This implies a_{m+i} = a_{l+i} for i = 1, ..., k.
Let the period candidate be d = l - m > 0. We have shown a_j = a_{j+d} for k consecutive values starting at j = m+1.

Step 4: Inductive Extension to Full Periodicity.

T_{m+1} = (a_{m+2}, ..., a_{m+k+1})
T_{l+1} = (a_{l+2}, ..., a_{l+k+1})
Since T_m = T_l, we know a_{m+i} = a_{l+i} for i=1, ..., k. Thus, the first k-1 elements of T_{m+1} and T_{l+1} are identical.
