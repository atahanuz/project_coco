**Analysis of the condition $a_{ij} = R_i + C_j$**

1.  **Row-wise Difference Invariance:**
    Consider any two entries in the same row $i$, say $a_{i j_1}$ and $a_{i j_2}$.
    $a_{i j_1} = R_i + C_{j_1}$
    $a_{i j_2} = R_i + C_{j_2}$
    Subtracting these yields:
    $a_{i j_1} - a_{i j_2} = C_{j_1} - C_{j_2}$.
    This difference depends only on the column indices $j_1$ and $j_2$, and is independent of the row $i$.

2.  **Column-wise Difference Invariance:**
    Similarly, consider any two entries in the same column $j$, say $a_{i_1 j}$ and $a_{i_2 j}$.
    $a_{i_1 j} = R_{i_1} + C_j$
    $a_{i_2 j} = R_{i_2} + C_j$
    Subtracting these yields:
    $a_{i_1 j} - a_{i_2 j} = R_{i_1} - R_{i_2}$.
    This difference depends only on the row indices $i_1$ and $i_2$, and is independent of the column $j$.

3.  **Consequences for $R$ and $C$:**
    The difference requirements *guarantee* the existence of vectors $R$ and $C$ satisfying $a_{ij} = R_i + C_j$, provided the difference constraints hold for the matrix entries.
    If we fix $R_1 = 0$, the vectors $C_j$ are determined by $C_j = a_{1j} - R_1 = a_{1j}$.

    This simplifies to the condition: $a_{ij} - a_{i1} - a_{1j} + a_{11} = 0$.
