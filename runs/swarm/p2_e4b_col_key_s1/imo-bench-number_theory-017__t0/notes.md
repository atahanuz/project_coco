### Analysis of the Pretty Condition
The pretty condition is defined as $m\lceil n\alpha \rceil - n \lfloor m\alpha \rfloor = k$. Since $\alpha$ is irrational, for any positive integers $m$ and $n$, $m\alpha$ and $n\alpha$ are irrational. Thus, $\lceil x \rceil = \lfloor x \rfloor + 1$ for $x=m\alpha$ and $x=n\alpha$.

Substituting these definitions:
$$m(\lfloor n\alpha \rfloor + 1) - n \lfloor m\alpha \rfloor = k$$
$$m\lfloor n\alpha \rfloor - n \lfloor m\alpha \rfloor = k - m$$

Next, we use the definition of the fractional part: $\lfloor x \rfloor = x - \{x\}$.
$$m(n\alpha - \{n\alpha\}) - n(m\alpha - \{m\alpha\}) = k - m$$
$$mn\alpha - m\{n\alpha\} - mn\alpha + n\{m\alpha\} = k - m$$
This simplifies to the fundamental necessary condition for a pair $(m, n)$ to be "pretty":
$$n\{m\alpha\} - m\{n\alpha\} = k - m$$

### Necessary Structural Properties (Independent of $\alpha$)
Since $0 \le \{x\} < 1$, we can bound the left-hand side (LHS):
$$-m < n\{m\alpha\} - m\{n\alpha\} < n$$
Since the LHS must equal the integer $k-m$, we derive the necessary constraints:
1. $k - m < n \implies k < m + n$.
2. $-m < k - m \implies 0 < k$ (which is given).

Therefore, a prerequisite for any pretty pair $(m, n)$ is $m+n > k$.

### Investigation of the Cool Condition
A pair $(m, n)$ is "cool" if neither $(m-n, n)$ nor $(m, n-m)$ are pretty (assuming the resulting pairs are positive integers, i.e., $m>n$ for the first check, and $n>m$ for the second check).
