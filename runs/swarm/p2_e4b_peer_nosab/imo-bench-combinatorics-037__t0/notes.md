**Proof for Task 1 (W1): $S \subseteq T$**

Let $S$ be an arbitrary Bachata subset of $\{0, 1, 2, \ldots\}$. By definition, $S$ must satisfy:
1. $0 \in S$.
2. If $n \in S$, then $n + 11 \in S$.
3. If $n \in S$, then $n + 20 \in S$.

The target set $T$ is defined as $T = \{11a + 20b \mid a, b \ge 0\}$. We must show that $S \subseteq T$.

We use an argument based on the constructive nature of $S$. Any element $n \in S$ must be generated starting from 0 by a finite sequence of additions of 11 and 20.

1. **Base Case:** The starting element is $0$. Since $0 = 11(0) + 20(0)$, $0 \in T$.
2. **Inductive/Constructive Step:** Assume $n \in S$. If $n > 0$, then $n$ must have been generated from a previous element $n' \in S$ such that either $n = n' + 11$ or $n = n' + 20$.
    *   Case 1: $n = n' + 11$. Since $n' \in S$, by the definition of $S$, $n'$ must itself be representable as $11a' + 20b'$ for some $a', b' \ge 0$. Then $n = (11a' + 20b') + 11 = 11(a'+1) + 20b'$. Since $a'+1 \ge 0$ and $b' \ge 0$, $n \in T$.
    *   Case 2: $n = n' + 20$. Similarly, $n' = 11a' + 20b'$. Then $n = (11a' + 20b') + 20 = 11a' + 20(b'+1)$. Since $a' \ge 0$ and $b'+1 \ge 0$, $n \in T$.

Since every element $n \in S$ must have been generated by this process, every element $n \in S$ must be of the form $11a + 20b$ with $a, b \ge 0$. Therefore, $S \subseteq T$.

(Note: The reverse inclusion $T \subseteq S$ is trivial, as $T$ is defined as the closure of $\{0\}$ under these operations, satisfying the definition of a Bachata set.)
The final conclusion is that $S=T$.
